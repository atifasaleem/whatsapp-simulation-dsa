# whatsapp-simulation-dsa
Mini WhatsApp simulation system using C++ and DSA concepts
WhatsApp Simulation DSA Project

This project is a mini WhatsApp-like chat system built in C++ using Data Structures and Algorithms (DSA) concepts.

It simulates basic messaging features between two users (Sobia and Atifa) using linked lists to store messages.

Features:
- Send messages between two users
- Schedule messages with delay (simulation of message delivery)
- Delete messages for everyone
- Dual chat view (split screen simulation)
- Message tracking using unique IDs

Concepts Used:
- Linked List (for storing messages)
- Dynamic memory allocation (new/delete)
- Function-based modular programming
- Basic system delay simulation (sleep function)

How it works:
- Each message is stored as a node in a linked list
- Two separate lists simulate both users' chat history
- Messages can be added, delayed, updated, or deleted using message ID
